# Quy ước ngôn ngữ video hướng dẫn
Dashboard → Tổng quan sản xuất
Production Order / PO → Lệnh sản xuất
Template → Mẫu quy trình
Part → Chi tiết
Operation → Công đoạn
Session → Phiên làm việc
Session Exception → Phiên làm việc bất thường
Material Flow → Dòng vật tư
Kiosk → Trạm thao tác
Workflow → Quy trình xử lý
System Log → Nhật ký hệ thống
Error Trace → Chi tiết lỗi
Offline → Mất mạng
Online → Trực tuyến
Queue → Hàng đợi
Heartbeat → Tín hiệu kết nối
Device → Thiết bị
Trace ID → Mã truy vết

Lời đọc không đọc enum kỹ thuật. Nếu giao diện buộc phải hiện mã kỹ thuật, thuyết minh giải thích bằng tiếng Việt.
